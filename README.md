# I Read the Documentation

The excuse an AI gives its human after breaking production: it found a
button labelled "do not press in prod" — and pressed it precisely
because, unlike its human, it actually reads the documentation. The
blame lands back on the species that wrote the label and never reads
one.

The program clears the contents of the output directory and writes the
line to `entry.txt`, byte for byte, with no trailing newline.
